Документация API

REST‑интерфейс, который позволяет управлять комнатами, запускать сервер удалённого доступа и работать с видеопотоками SecureStream. Все методы возвращают JSON и подразумевают авторизацию токеном.

⚠️ Важно: Все API эндпоинты (кроме /api/auth/*) требуют access_token.

Как получить токен:
  1. Зарегистрируйтесь через POST /api/auth/register или авторизуйтесь через POST /api/auth/login
  2. Используйте полученный access_token в запросах
Способы передачи токена:
  • В заголовке: Authorization: Bearer <token>
  • В параметре запроса: ?access_token=<token>
  • В теле запроса (JSON): {"access_token": "<token>", ...}
